01Scope and application

EMA Lightning is a Turkish-focused text-to-speech app for iOS and iPadOS. It provides speech using the EMA model, local recording history, a personal pronunciation dictionary, MP3 audio and captioned MP4 export. An Apple system voice is available as an alternative preview. This policy covers the application offered by EKATECH and this information website.

02Text and audio processing

EMA speech generation takes place on your device. In the reviewed application code, your input, pronunciation-adjusted text and generated audio are not sent to a remote TTS server. The model and runtime are bundled with the app; no initial model download is needed. ONNX Runtime Web and the Turkish normalizer run in WebKit using CPU/WebAssembly. The on-device 127.0.0.1 connection serves bundled files only; it is not a transfer to an internet server. We do not collect your text or audio for model training in this flow.

03Internet and dictionary updates

Generating speech with the EMA model does not require internet access. Downloading or updating the app, opening external links and online sharing may require a connection. The Apple preview uses AVSpeechSynthesizer; availability or download of a Turkish system voice depends on Apple and your device settings.

Versions with the central dictionary feature: These versions may request the dictionary version and public pronunciation rules over HTTPS from speak.ekatech.net on launch/activation and when manually triggered. After a successful check, automatic checks are spaced 24 hours apart, with retry delays after errors. Requests are read-only; input text, generated audio and personal dictionary entries are not uploaded. Bundled or cached rules remain usable offline. Central dictionary synchronization was included in main through PR #11 on November 10, 2026.

04Personal data and sharing

The reviewed main source contains no account creation, advertising identifier, advertising SDK, behavioral analytics or automatic remote crash reporting. However, the application stores text and audio on your device; we do not claim that no data is processed.

When you choose Share, the selected file or report is passed to the iOS share sheet. MP4 output can contain the spoken text, and file names can contain information derived from recording titles. The recipient app or service processes it under its own privacy terms. Deleting data in EMA Lightning does not delete shared copies.

05Third parties and diagnostics

The EMA model, Turkish normalizer, ONNX Runtime Web and lamejs/LAME MP3 encoder are bundled in the app. No remote model, CDN or encoding service is called for these components. The app uses Apple system components including WebKit, AVFoundation and JavaScriptCore.

Developer Mode provides local diagnostic stages, timings and errors. The source file telemetry.js is a local bridge and does not send reports to remote analytics. You can choose to copy or share a report. Reports can include device model, iOS/app versions and technical errors; the code attempts to remove input text and personal pronunciation values. Review reports before sharing them.

If you email support, your email address, message and any attachments are processed to respond to your request. You do not need to send sensitive text or audio. External links such as GitHub are governed by the destination service’s policy.

06Permissions

The reviewed application configuration does not request microphone, camera, location, contacts or speech recognition permission. The app generates audio and does not record your microphone. Background audio playback is supported. File and report sharing uses the iOS share sheet at your request. The local model server uses an on-device loopback connection only.

07Retention and deletion

EMA-generated audio is automatically saved as WAV files with original text, title, creation date, duration and engine information in the app’s local archive. Recordings remain until you delete them or delete the app. Delete an individual recording in History or all recordings using Settings → Delete all recordings. Personal pronunciation entries and appearance/developer preferences are stored in UserDefaults; personal rules can be deleted in the dictionary screen.

Startup cleanup attempts to remove temporary MP3/MP4 exports older than 24 hours; deletion at exactly 24 hours is not guaranteed. Deleting the app removes local app data; iOS Offload App may retain it. Delete copies saved to Files or other services separately.

Depending on system settings, iCloud/device backups can include copies of local data; the reviewed main source does not exclude the recording archive from backups. Manage backups in Apple settings. A fixed retention period for support correspondence has not been verified, so no duration is promised here; contact us to request deletion.

08This website and network data

This information website is delivered over HTTPS through Cloudflare. Access to the website or dictionary API may involve infrastructure processing of technical connection information such as IP address, request time, requested path and client headers. The reviewed dictionary API uses IP addresses for rate limiting and does not write app text or audio to its database. An exact retention period for infrastructure security processing has not been verified in this review.

No analytics, advertising, tracking cookies, third-party fonts or scripts have been added to these pages. If you change the theme, the preference is stored only in your browser’s local storage; system theme is the default. Language links also work without JavaScript. See Cloudflare’s privacy policy for its processing.

09Children’s privacy

We do not ask children to send personal information. Because text can contain personal information, parents and guardians should supervise children’s device use and sharing choices. If you believe a child’s information was sent to us through support, contact us to request deletion.

10Security

Local recording files use iOS file protection. The EMA WebKit session uses a non-persistent data store, and local content security rules restrict external resources. The website and central dictionary connections use HTTPS. Device locks, operating system updates, backup settings and sharing choices also affect security. No storage or transmission method can be guaranteed absolutely secure.

11Policy changes

12Contact and requests

For privacy questions, deletion of support correspondence and related data requests, contact EKATECH at contact@ekatech.net. We cannot remotely access your local recordings, so deletion of on-device content is performed in the app. Include only the information needed to explain your request.

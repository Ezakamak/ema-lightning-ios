# EMA Lightning iOS

Independent iOS project inspired by [EMA Lightning](https://github.com/canberk7/ema-lightning) by Canberk Aslan and the [ONNX/web adaptation](https://github.com/ozcancelik/ema-lightning-web) by Özcan Çelik.

Native iOS foundation, licensing audit, contribution documentation and unsigned build automation are being prepared in a pull request.

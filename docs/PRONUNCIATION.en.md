# Pronunciation dictionary

Settings → Pronunciation dictionary provides 158 original approximate Turkish
respellings of frequent brands, apps, developer/AI terms, acronyms and loanwords.
Examples: iPhone → ayfon, Apple → epıl, WhatsApp → vatsap. These are editable
suggestions, not an authoritative phonetic dictionary or an audibly validated
EMA dataset. No external dictionary, second voice model or online service is used.

Add/edit/delete personal rules, disable a built-in through a personal override,
or disable the bundled list while keeping personal entries. Rules are local,
apply to the next EMA request and never change the original editor/history/video
text or old recordings. Apple preview is unaffected. Match whole words/phrases;
longest phrase wins, personal entries override the same built-in key, replacements
never cascade. Turkish i/ı stays distinct, while ASCII brands accept dotted İ.
Turkish apostrophe suffixes are retained. Limit: 300 personal rules, 64 source
characters, 128 phonetic characters, 8,000 expanded synthesis characters.

Prose preparation removes list/bracket/quote/Markdown formatting while keeping
content and pauses. It shields raw web/email addresses and basic numeric
expressions; meaningful signs, times, decimal numbers and dates are not globally
stripped. Markdown links speak their label. This is not a complete markup,
programming-language or math interpreter. Detailed examples are in the Turkish
guide and optional test source. Original normalizer/model binaries stay unchanged.

No test, build or new download package was run for this follow-up, at the
maintainer's request. Regression examples have been added for a future optional
manual run; no runtime or physical-device pass is claimed for this new code.
